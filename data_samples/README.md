# Data note

This public portfolio repository intentionally excludes the full raw Corporación Favorita training dataset and heavy modeling-table shards.

Included here are compact, project-generated samples and metadata that make the feature design and final outputs reviewable without bloating the repository.

To reproduce the original analysis, obtain the **Corporación Favorita Grocery Sales Forecasting / Store Sales - Time Series Forecasting** source data from Kaggle and follow the notebook chronology.

The final Power BI `.pbix` is self-contained with imported dashboard-ready data.
